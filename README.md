# curb

**This project is decommissioned.** curb is no longer developed, published, or installable. The repository is archived
and kept for reference only.

All released versions have been retracted from the Go module proxy and the Homebrew tap has been removed, and the 
Binaries already installed keep working, but receive no updates.

curb was a small HTTPS-only transport utility written in Go using only the standard library. It streamed JSON and other
text to stdout, saved binaries to disk, and offered an opt-in `--vet` mode that buffered and checked a body before
piping it to a shell. The source remains in this repository's history.
