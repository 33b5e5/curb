curb

A small, HTTPS-only transport utility for the command line. Written in Go, using only the standard library.

curb picks the right behavior based on what the server returns and whether the output is going to a human or a pipe: stream JSON and HTML to stdout, save binaries to disk, vet scripts before piping to a shell.

Install

go install gocurb.dev/curb@latest

Try it

curb https://api.example.com/users
curb https://example.com/release.tar.gz
curb --vet https://install.example.com/setup.sh | sh
